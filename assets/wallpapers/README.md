# assets/wallpapers/ — duvar kağıtları

**İsteğe bağlı.** Buraya hiçbir şey koymazsan sistem, `karanos-theme` paketinin
kod içinde ürettiği degrade duvar kağıtlarıyla gelir (turuncu/sarı, koyu ve
açık tema için birer tane). ISO'ya yer kaybettirmez.

Kendi duvar kağıtlarını koymak istersen:

```
assets/wallpapers/karanos-01.jpg
assets/wallpapers/karanos-02.jpg
...
```

| Konu | Değer |
|---|---|
| Biçim | JPG (fotoğraf için) veya PNG (düz renk/degrade için) |
| Çözünürlük | **1920 × 1080** (en az). 4K koyarsan ISO şişer. |
| Dosya boyutu | Tanesi 1 MB altı |
| Adlandırma | `karanos-NN.jpg`, `NN` = 01'den başlayan iki hane |
| Toplam | En fazla 6 tane — ISO 1.5 GB sınırı için |

Setup sihirbazındaki ve Ayarlar > Görünüm'deki duvar kağıdı seçici bu klasörü
tarar; ayrıca kullanıcı kendi dosyasını da seçebilir.
